# Dataset Card: Prompt Radar Synthetic Dataset

## Назначение

Набор предназначен для аналитики запросов к корпоративным ИИ-агентам:

1. извлечение фактического пользовательского запроса из диалога и контекста;
2. классификация по типам задач;
3. обнаружение устойчивых сценариев использования;
4. выявление проблемных формулировок;
5. демонстрация командной, временной и бизнес-аналитики на дашборде.

## Состав

Demo содержит 740 событий, validation — 185 событий. Все записи синтетические
и имеют `is_synthetic=true`. Validation labels хранятся отдельно и никогда не
передаются классификатору.

Комплект охватывает 31 исходную тему и 6 дополнительных тем. Дополнения
закрывают отсутствовавшие категории помощи с кодом, нерабочих запросов и
неопределённых запросов. В итоговой taxonomy присутствуют все 12 категорий
backend и 35 scenario labels.

## Бизнес-поля

Каждое demo-событие содержит пользователя, команду и направление. Не реже
каждого шестого события присутствуют синтетический ответ, usage, статус,
latency, rating, `task_completed` и `estimated_minutes_saved`. Благодаря этому
дашборд показывает не только объём запросов, но и проблемы выполнения,
направления использования и механику оценки эффективности.

## Edge cases

- 31 неоднозначная формулировка;
- 31 запрос с отсутствующим контекстом;
- 31 запрос с несколькими намерениями;
- 12 контекстов строго больше 100 000 prompt-токенов.

Контексты до 100 000 токенов поддерживаются системой. Oversized-примеры
намеренно используют 100 001 prompt-токен и проверяют только превышение
поддерживаемой границы.

## Воспроизводимость

```powershell
python scripts/generate_project_dataset.py
python scripts/validate_project_dataset.py
```

Фиксированный seed: `20260725`. Генератор детерминированно пересоздаёт данные,
манифест, metadata и контрольные суммы. Валидатор проверяет Pydantic-схему,
ID, extraction, утечки, категории, кластеризацию, edge cases и SHA-256
настоящими функциями backend.

## Текущий offline baseline

- category accuracy: 0.9514;
- scenario pairwise precision: см. `quality_report.json`;
- scenario pairwise F1: 0.8634;
- recall для ambiguous, missing context, multiple intents и oversized: 1.0000.

## Ограничения

1. Данные и ответы синтетические.
2. Частотность и динамика созданы для демонстрации.
3. Синтетическая экономия времени не является доказательством ROI.
4. Качество ответов и фактологическая точность агента этим набором не
   измеряются.
5. Перед production-использованием нужен обезличенный real-world holdout с
   независимой разметкой.
